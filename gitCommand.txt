
---------------------------------------------------------
|                      For  Developer                   |
---------------------------------------------------------
git clone git_url ៖ clone project from github
git checkout dev ៖ ប្តូរទៅកាន់សាខា dev (Branch រួម)។
git pull ៖ ទាញយកកូដថ្មីៗចុងក្រោយបង្អស់ពី Server មកដាក់ក្នុង dev។
git checkout your_branch ៖ ប្តូរមកកាន់ branch របស់អ្នកវិញ (your_branch)។
git merge dev ៖ បញ្ចូលកូដថ្មីៗពី dev ចូលមកក្នុង your_branch (ដើម្បីការពារ ឬដោះស្រាយ Conflict)។
git checkout dev ៖ ប្តូរទៅកាន់ branch dev វិញ។
git merge your_branch ៖ បញ្ចូលកូដដែលអ្នកបានធ្វើរួចពី your_branch ទៅក្នុងសាខា dev។
ចំណាំ៖ បន្ទាប់ពីជំហានចុងក្រោយ អ្នកគួរតែរត់ពាក្យបញ្ជា git push នៅលើ branch dev ដើម្បីបញ្ជូនកូដថ្មីនេះឡើងទៅកាន់ Remote Server (GitHub/GitLab)។

១. តាមដានការងារ និងពិនិត្យមើល Progress (Status & Progress)

git status
ពិនិត្យមើលស្ថានភាពទូទៅនៃ Repository បច្ចុប្បន្ន។

git log --oneline --graph --all
មើលប្រវត្តិ Commits និងរចនាសម្ព័ន្ធ Branch ទាំងអស់ជាទម្រង់ដើមឈើ (Graph) សង្ខេប ស្រួលមើល។

git log --author="ឈ្មោះ Developer"
ស្រង់មើលតែ Commits ណាដែលធ្វើឡើងដោយ Developer ជាក់លាក់ណាម្នាក់។

git log --since="1 week ago"
មើលការងារដែលក្រុមធ្វើរួចក្នុងអំឡុង ១ សប្តាហ៍ចុងក្រោយ (អាចដូរជា 3 days ago ឬ yesterday)។

២. គ្រប់គ្រង Branch និង Release (Branch & Release Management)

git branch -a
បង្ហាញឈ្មោះ Branch ទាំងអស់ (ទាំងក្នុងម៉ាស៊ីន និងលើ Server) ដើម្បីដឹងថាមាន Feature អ្វីខ្លះកំពុងធ្វើ។

git checkout <ឈ្មោះ_branch>
ប្តូរទៅកាន់ Branch ណាមួយដើម្បីពិនិត្យ ឬធ្វើការ Test កូដដោយផ្ទាល់។

git tag -a v1.0.0 -m "Release version 1.0.0"
បង្កើត Tag ដាក់លេខ Version សម្រាប់ទិន្នន័យ Release ផ្លូវការ។

git push origin --tags
បញ្ជូន Version Tags ទាំងនោះឡើងទៅកាន់ Remote Server (GitHub/GitLab)។

៣. ប្រៀបធៀប និងពិនិត្យកូដ (Comparing & Reviewing)

git diff main..dev
ប្រៀបធៀបមើលភាពខុសគ្នារវាង Branch ពីរ (ឧទាហរណ៍៖ មើលថាកូដក្នុង dev ខុសពី main កម្រិតណា)។

git blame <ឈ្មោះ_file>
មើលលម្អិតជួរនីមួយៗក្នុង File ថាអ្នកណាជាអ្នកសរសេរ ឬកែប្រែ និងធ្វើនៅពេលណា។

៤. សម្អាតទិន្នន័យចាស់ៗ (Cleanup)

git fetch --prune
លុបឈ្មោះ Branch ណាដែលគេបាន Merge ឬលុបចោលនៅលើ Server ចេញពីម៉ាស៊ីនរបស់អ្នក ដើម្បីឱ្យបញ្ជី Branch ស្អាត។
